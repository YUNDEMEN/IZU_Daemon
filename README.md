# IZU

### 1 应用场景说明：防火门 
- 两个连着的车间会有一个猫道，在猫道的两侧，各自会安装一个防火门
- 当其中一个车间着火后，会通过某种机制通知控制这块区域的IZU，IZU再通知OHTC
- OHTC得知某个防火门有火警后，会在30秒内完成清场工作
  * 防火门附近10米距离内，天车只出不进
  * 当防火门附近10米距离内不再有天车后，通知IZU清场工作完成
 - IZU再通知防火门，可以关门了
 
 #### 1.1 实现方案
 - OHTC把防火门附近10米内的站点都搜索出来，
    * 并找到这些站点对应的segment
    * OHTC找出所有停在这些站点的idle天车，并发送移动指令给天车到下一个停车点
 - OHTC设置这些segement的属性status=disable
 - OHTC查找出所有会路过这些点的天车，并发送abort/cancle指令
