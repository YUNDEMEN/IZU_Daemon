# IZU

### 1 应用场景说明：防火门 
- 两个连着的车间会有一个猫道，在猫道的两侧，各自会安装一个防火门
- 当其中一个车间着火后，会通过某种机制通知控制这块区域的IZU，IZU再通知OHTC
- OHTC得知某个防火门有火警后，会在30秒内完成清场工作
  * 防火门附近10米距离内，天车只出不进
  * 当防火门附近10米距离内不再有天车后，通知IZU清场工作完成
 - IZU再通知防火门，可以关门了
 
 #### 1.1 实现方案
 - OHTC把防火门附近10米内的站点都搜索出来，
    * 并找到这些站点对应的segment
    * OHTC找出所有停在这些站点的idle天车，并发送移动指令给天车到下一个停车点
 - OHTC设置这些segement的属性status=disable
 - OHTC查找出所有会路过这些点的天车，并发送abort/cancle指令
 
 ### 2 应用场景说明：自动门 
 - 在某些轨道上会部署自动门，常态是关闭的，有天车要通过的时候才打开
 - 部署自动门的目的是分割在同一个车间内部的，不同洁净等级的无尘室，防止高洁净等级的无尘室被低洁净等级的无尘室污染
 - 需求
   * 自动门的开，关需要3-5秒
   * 自动门开一次最多10秒就必须关闭，否则就会产生污染
  
  #### 2.1 相关参数和说明
  - 按照天车3.3m/s的运行速度，必须在天车距离自动门最少16.5米时，就要通知自动门打开
  - 自动门一次打开只能坚持10秒，这意味着只有距离自动门33米内的天车才有可能通过。超过这个距离的天车必须等下一次自动门开
  - 天车通过自动门后，需要汇报给OHTC已经成功通过。OHTC然后通知自动门可以关闭了
  - 但是如果有连续的天车排队通过自动门，那么OHTC必须要判断，什么时候才可以通知自动门去关闭
  - 一次搬运，最多经过两个自动门
  
  #### 2.2 解决方案
  1. OHTC发送搬运命令给天车后，检查搬运路径是否要通过自动门
     - 是，把天车ID加入到集合R，同时分别计算好距离自动门16.5米的点p165和33米的点p330, 以及自动门后下一站exit_point
       * { ohtID:  { autoDoorID, p165, p330, exit_point } }
     - 当天车完成搬运命令后，把天车从集合R中移除
  2. 当OHTC收到天车汇报当前位置，检查天车是否在集合R中
     - 是，在判断天车是否已经进入了自动门的范围[p330, autoDoor], 或者[p165, autoDorr]
         * 检查自动门是否已经打开了(status=on|off)，打开多长时间了(current_time - open_time)
         * 如果status = off 且 oht in [p330, autoDorr], 不做任何事情
         * 如果status = off 且 oht in [p165, autoDorr], 通知自动门开门
         * 如果status = on
           * 计算天车要花多长时间才能通过自动门：cost = (autoDoor.point - oht.current_point)/3.3
           * 计算自动门还有多久要关门：duration = 10 - (current_time - open_time)
           * 如果 cost > duration, 意味着天车来不及在自动门关门前通过，天车需要提前准备刹车(刹车在自动门前一站？)
           * 如果 cost < duration, 意味着天车来得及在自动门关门前通过，天车可以全速前进
         * 当天车通过了exit_point, OHTC判断是否要通知自动门关门
           * 检查集合R, 是否有搬运路径通过autoDoorID的天车，得到集合T
           * 检查集合T内每个天车的当前位置，判断有天车来得及通过这个已经打开的自动门
              * 计算天车要花多长时间才能通过自动门：cost = (autoDoor.point - oht.current_point)/3.3
              * 计算自动门还有多久要关门：duration = 10 - (current_time - open_time)
              * 如果 cost > duration, 意味着天车来不及在自动门关门前通过，天车需要提前准备刹车(刹车在自动门前一站？)
              * 如果 cost < duration, 意味着天车来得及在自动门关门前通过，天车可以全速前进
              * 只有所有的天车都来不及通过这个打开的自动门，才通知自动门关门
